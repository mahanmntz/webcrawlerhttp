🏛️ Distributed System Topology

How the decoupled services cooperate through Redis message brokers and state queues:

+---------------------------------------------------------------------------------+ | Client / Ingestion (Makefile / seeds.txt) | +---------------------------------------+-----------------------------------------+ | POST /api/jobs (or /api/jobs/batch) v +---------------------------------------------------------------------------------+ | API Gateway (TypeScript + Fastify) | | - Input validation & Schema checking (TypeBox / Fastify schema) | | - SADD frontier:seen -> Deduplication check (returns 409 Conflict if seen) | +---------------------------------------+-----------------------------------------+ | LPUSH frontier:queue (CrawlTarget) v +---------------------------------------------------------------------------------+ | Redis 7.2 Broker & State | | - frontier:queue : Pending crawl tasks | | - frontier:processing : In-flight crawl tasks (At-least-once via BRPOPLPUSH) | | - frontier:seen : Set for O(1) URL deduplication | | - politeness:host:<d> : Per-domain leases with TTL (SET NX PX) | | - queue:raw_pages : Downloaded HTML bodies | | - queue:parsed_docs : Clean structured documents | +--------------------+---------------------------------------+--------------------+ | BRPOPLPUSH ^ LPUSH v | (Discovered URLs) +---------------------------------------+ +----------------+--------------------+ | Crawler Engine (Go) | | Parser & Scraper (Python) | | - Fixed Worker Pool (sync.WaitGroup) | | - BeautifulSoup / lxml DOM parsing | | - Custom http.Transport Keep-Alive | | - URL Canonicalization (urljoin) | | - MaxIdleConnsPerHost: 50 | | - Script/Image asset filtering | | - Domain Politeness coordinator | | - SADD seen check -> Re-enqueue | +--------------------+------------------+ +-------------------------------------+ | LPUSH queue:raw_pages (RawPage JSON) +--------------------------------------->
Key Architectural Principles (Alex Xu Chapter 9):
• At-Least-Once Delivery: Tasks are popped using BRPOPLPUSH into a processing queue. If a worker crashes mid-fetch, tasks are never permanently lost.
• Decoupled Scraping: High-throughput Go network downloads are decoupled from CPU-heavy HTML parsing in Python through Redis buffers.
• Politeness by Design: Prevents unintentional DoS against target domains by leasing domain tokens via Redis TTLs.
